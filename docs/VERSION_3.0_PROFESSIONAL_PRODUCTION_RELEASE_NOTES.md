# BothNow Camera 3.0 – Professional Production Edition

## Teleprompter
- Edit and save a presenter script locally on the device.
- Display the script over the live camera preview while recording.
- Start, pause, and reset scrolling.
- Adjust scrolling speed.
- Script text is not burned into either exported video.

## Existing camera features retained
- Dual landscape and portrait video export.
- Independent portrait and landscape watermark controls.
- Movable portrait frame, pinch zoom, tap-to-focus and exposure compensation.
- Composition guides, photo timer, recording timer and BothNow media gallery.
